  <div class="project-title">Cumene Production Process Design & ML Integration</div>
  <p class="section-subtitle">제15회 전국 화학공학 공정설계 경진대회</p>
  <p class="project-desc">
    Simulated the cumene production process using Aveva Process Simulation, including reactor and distillation unit modeling<br>
    Preprocessed 8 days of process operating data through steady-state data preprocessing<br>
    Selected and developed an ML model sized to the preprocessed dataset, then exported it to ONNX<br>
    Evaluated the ML model's performance using LOOCV (leave-one-out cross-validation)<br>
    Integrated the simulation program with the ML model<br>
    Ran case studies across various process operating conditions<br>
    Analyzed the case study results and built a recommendation model to derive the optimal operating conditions
  </p>
